# Аудио-транскрипция (GigaAM + silero-vad)

## When to use

Распознавание аудио- и видео-записей (встречи, диктофон, запись экрана Google Meet/Zoom/OBS) через GigaAM — русская ASR. Возвращает `.md` с транскрипцией рядом с исходником.

**Принимает:**
- Аудио: `m4a/mp3/wav/ogg/flac`
- Видео-контейнеры: `mp4/webm/mkv/mov/m4v/avi` — `ffmpeg` автоматически извлекает аудиодорожку, видеотрек игнорируется. Отдельный аудио-файл не создаётся, результат — сразу `.md`.

- Флаг `--fast` переключает на быструю модель v2_ctc (черновик в 3-4 раза быстрее).
- Длинные файлы (≥25с) нарезаются через silero-vad — работает out-of-the-box, без токенов.

**Триггеры:** "транскрибируй", "расшифруй аудио", "расшифруй видео", "запись встречи", "audio", "webm/mp4 с записью".

## Что делать

### 0. Определи путь к скрипту

Найди расположение этого SKILL.md → поднимись на 3 уровня (`../../..`) → это корень скилла. Скрипт транскрипции: `<root>/.agents/skills/audio/scripts/transcribe.sh`. Запомни этот путь как `$TRANSCRIBE_SH`.

### 1. Определи `$AUDIO`

Абсолютный путь к аудио- или видео-файлу:
- Если в `$ARGUMENTS` передан путь — используй
- Если в диалоге упомянут файл (в т.ч. `.webm`, `.mp4`, `.mkv` и т.п.) — возьми путь оттуда
- Иначе — спроси пользователя

### 2. Опциональные флаги

- `--fast` — если пользователь сказал «быстро», «черновик», «fast» (переключает на модель v2_ctc)
- `--out <path>` — если пользователь явно указал путь к .md

### 3. Запусти транскрипцию

```
bash "$TRANSCRIBE_SH" "$AUDIO" [--out "$OUT"] [--fast]
```

Первый запуск создаст venv и скачает веса (~750MB суммарно, 2-5 мин) — скрипт сам сообщит в stderr `[warm-up] ...`. Это нормально.

### 4. Обработка exit code

| Код | Действие                                                                                      |
|-----|-----------------------------------------------------------------------------------------------|
| 0   | Прочитай результирующий `.md` через Read, покажи первые ~1500 символов + путь к полному файлу |
| 1   | «Файл не найден: $AUDIO»                                                                      |
| 2   | «Не установлен ffmpeg. Поставь: `brew install ffmpeg`»                                        |
| 4   | «Ошибка GigaAM/silero-vad (см. stderr). Проверь что модели скачались и venv валиден»          |
| 5   | «Директория только для чтения. Передай `--out <путь>` в writable-директорию»                  |

## Диагностика (без аудио)

```
bash "$TRANSCRIBE_SH" --check
```

Синтезирует 1-сек WAV-тишину, прогоняет через `v2_ctc`, загружает silero-vad. Успешный прогон → venv + ffmpeg + gigaam + silero-vad работают.
